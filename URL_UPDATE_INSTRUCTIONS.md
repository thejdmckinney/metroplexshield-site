# 🔧 URL Update Instructions

## After Creating Your GitHub Repository

Once you create your GitHub repository, you'll need to replace the placeholder URLs with your actual GitHub username and repository name.

### What to Update:

Replace `yourusername` with your actual GitHub username in these files:

#### 1. **sitemap.xml**
- Replace: `https://yourusername.github.io/metroplex-shield-website/`
- With: `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`

#### 2. **robots.txt**  
- Replace: `https://yourusername.github.io/metroplex-shield-website/sitemap.xml`
- With: `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/sitemap.xml`

#### 3. **index.html** (multiple locations)
- Replace all instances of: `https://yourusername.github.io/metroplex-shield-website/`
- With: `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`

### Quick Find & Replace:
1. **Open each file** in a text editor
2. **Find**: `yourusername.github.io/metroplex-shield-website`
3. **Replace with**: `YOUR-USERNAME.github.io/YOUR-REPO-NAME`
4. **Save** the files

### Example:
If your GitHub username is `jeremy123` and you name your repository `metroplex-website`:
- Replace: `yourusername.github.io/metroplex-shield-website`
- With: `jeremy123.github.io/metroplex-website`

## ✅ Ready for GitHub Pages!

Your website files are now prepared for GitHub Pages deployment. Once you update the URLs with your actual GitHub information, everything will work perfectly!
