# ✅ GitHub Pages Deployment Checklist

## 🚀 **Ready to Deploy Your MetroPlex Shield Website**

Your website is **100% ready** for GitHub Pages! Here's your simple deployment checklist:

---

## **Step 1: Create GitHub Repository (3 minutes)**
- [ ] Go to **github.com** and sign in
- [ ] Click **"New repository"** (green button)
- [ ] Repository name: `metroplex-shield-website` (or your choice)
- [ ] Set to **Public** (required for free GitHub Pages)
- [ ] ✅ Check **"Add a README file"**
- [ ] Click **"Create repository"**

---

## **Step 2: Upload Website Files (5 minutes)**
- [ ] Click **"uploading an existing file"** link
- [ ] **Drag ALL these files** from your computer:
  ```
  ✅ index.html
  ✅ essential-plan.html
  ✅ guardian-plan.html
  ✅ premier-plan.html
  ✅ sitemap.xml
  ✅ robots.txt
  ✅ assets/ folder (with css/, js/, images/ inside)
  ```
- [ ] Write commit message: **"Launch MetroPlex Shield website"**
- [ ] Click **"Commit changes"**

---

## **Step 3: Update URLs (2 minutes)**
After uploading, you need to update placeholder URLs:

- [ ] **Edit sitemap.xml** in GitHub
  - Find: `yourusername.github.io/metroplex-shield-website`
  - Replace with: `YOUR-GITHUB-USERNAME.github.io/YOUR-REPO-NAME`

- [ ] **Edit robots.txt** in GitHub  
  - Same replacement as above

- [ ] **Edit index.html** in GitHub
  - Same replacement in multiple locations

---

## **Step 4: Enable GitHub Pages (1 minute)**
- [ ] Go to **Settings** tab in your repository
- [ ] Click **"Pages"** in left menu
- [ ] Under **Source**, select **"Deploy from a branch"**
- [ ] Choose **"main"** branch and **"/ (root)"**
- [ ] Click **"Save"**

---

## **Step 5: Your Website Is Live! (5-10 minutes wait)**
- [ ] GitHub gives you live URL: `https://your-username.github.io/repo-name`
- [ ] Wait 5-10 minutes for first deployment
- [ ] **Test everything**:
  - [ ] Homepage loads correctly
  - [ ] All 3 plan pages work (Essential, Guardian, Premier)
  - [ ] Pricing toggles work (Monthly/Yearly)
  - [ ] Contact forms submit successfully
  - [ ] Stripe payment buttons work
  - [ ] Mobile version looks good
  - [ ] Logo displays properly

---

## **Step 6: Connect Custom Domain (Optional)**
If you own `metroplexshield.com`:
- [ ] In **Pages settings**, add custom domain
- [ ] Update DNS settings with your domain registrar
- [ ] GitHub provides free SSL certificate

---
